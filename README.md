# Telegram Auth Bot

Бот для авторизации в Telegram через API с подтверждением по номеру телефона.

## Функциональность

- Запрос номера телефона через кнопку
- Отправка кода подтверждения через Telegram API
- Верификация 5-значного кода
- Авторизация в аккаунте Telegram
